Projeto: S.O.P.R.O - Sistema de Operações e Pesquisa de Riscos Ocultos

Descrição:
Este projeto simula o terminal de uma organização secreta dedicada à catalogação e contenção de entidades paranormais. O sistema permite o gerenciamento completo (CRUD) de anomalias e dos sítios de contenção, com interface inspirada em terminais confidenciais, utilizando paleta escura e fontes monoespaçadas.

Tecnologias Utilizadas:
- Front-end: HTML5 semântico, CSS3 (Grid e Flexbox)
- Back-end: PHP procedural
- Banco de Dados: MySQL
- Gerenciamento de Estado: Sessões PHP ($_SESSION)

Estrutura do Projeto:
- /css: Folhas de estilo
- /uploads: Imagens das anomalias
- /includes: Partes reutilizáveis e scripts PHP
- /sql: Scripts SQL de criação do banco
- index.php, anomalia_registrar.php, anomalia_listar.php, anomalia_visualizar.php, anomalia_editar.php, anomalia_excluir.php, sitio_gerenciar.php

Uso de IA Generativa:
Os scripts deste projeto foram gerados com base em um prompt detalhado, que incluiu os seguintes pontos principais:
- Tema imersivo e confidencial (S.O.P.R.O)
- Estrutura de layout fixa com Grid e Flexbox
- Uso obrigatório de HTML5 semântico e CSS3
- PHP estritamente procedural, sem orientação a objetos
- CRUD completo para duas entidades (anomalias e sítios)
- Upload de imagens com nome único
- Feedback ao usuário via $_SESSION
- Organização em pastas e includes
- Scripts SQL para MySQL
- Documentação explicando o uso da IA e os requisitos do projeto

Este projeto foi desenvolvido como Avaliação Prática (AP1) da disciplina de Programação Web.
